# BASE-001 远端候选预检（2026-07-14）

## 结论

Correct Course 移除本机 SHA 不变量后，规范远端候选可以进入真实评估。当前 `main` 与现有 `v0.0.1-alpha.3` tag 均不能直接成为 BASE-001 tool source 基线：`aggo`、`gendb` 可隔离构建，但五个 protoc 插件全部因 root dependency 的 `go.sum` 校验项缺失而失败。

因此 Story 1.1 继续失败关闭，并需要受审 ag-core PR 修复插件模块后重新 preflight。不得修改下载后的 checkout 伪造通过。

## 环境

- canonical remote：`https://github.com/aif-go/ag-core.git`
- Go runtime：`go1.25.5 darwin/arm64`
- `GOTOOLCHAIN=local`
- `GOWORK=off`
- 每轮使用全新 shallow clone、独立 `GOMODCACHE`、`GOCACHE` 与输出目录
- 未复用开发机 PATH 中已有工具
- 未执行任何远端写操作

## 候选一：main

```text
ref=refs/heads/main
sha=d19907276b3ee32eff34e1de41604c7a94c249d0
```

结果：

- `aggo`：构建通过；`vcs.revision=d199072...`，`vcs.modified=false`。
- `gendb`：构建通过；`vcs.revision=d199072...`，`vcs.modified=false`。
- 五个 `protoc-gen-go-ag*`：构建失败。
- 五个插件当前均声明 `github.com/aif-go/ag-core v0.0.1-alpha.3`，但各自 `go.sum` 均缺少对应 root module 内容校验项。

首个确定性错误：

```text
missing go.sum entry needed to verify package github.com/aif-go/ag-core/tool/cmd/protoc-gen-go-agapi is provided by exactly one module
```

## 候选二：v0.0.1-alpha.3

```text
ref=refs/tags/v0.0.1-alpha.3
sha=1624c77ab90b12b77191c38005b64d59f8a0029e
```

结果：

- `aggo`：构建通过；VCS revision 精确匹配 tag SHA，`vcs.modified=false`。
- `gendb`：构建通过；VCS revision 精确匹配 tag SHA，`vcs.modified=false`。
- `protoc-gen-go-agapi`、`protoc-gen-go-aghertz`、`protoc-gen-go-agkitex`、`protoc-gen-go-agserver`、`protoc-gen-go-agservice`：均以同类缺失 `go.sum` 错误失败。

## 决策

1. 不选用 `main`：它是浮动分支，且五插件构建失败。
2. 不选用现有 `v0.0.1-alpha.3`：虽然 ref 可达，但七工具合同仅通过 2/7。
3. ag-core PR 应为五个插件补齐可验证、无本地 replace 的 `go.mod/go.sum` 依赖状态，并保持现有 CLI/模板行为。
4. PR 合并后以 merge SHA 重新执行 clean-build/provenance preflight；通过后再申请发布和保护 tool source immutable ref。
5. root dependency 候选仍需由 Architecture 在 PR 方案中批准并记录 version→SHA；不得在 PR 内引用未知 merge SHA。
