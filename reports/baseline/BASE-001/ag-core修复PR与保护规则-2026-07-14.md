## 根因与修复

五个 `protoc-gen-go-ag*` 子模块的依赖图落后于 root `github.com/aif-go/ag-core v0.0.1-alpha.3`：

- `go.sum` 缺少 root module 内容和 `go.mod` 校验项。
- 间接 Kitex/Protobuf/genproto 版本与 root module 的最小版本选择结果不一致。
- 在根 `go.work` 下本地构建可被 workspace 掩盖，而空 cache、`GOWORK=off` 的构建因校验项缺失失败。

PR 仅更新五个插件的 `go.mod/go.sum`，不改 CLI、生成模板、API 或生成物。
