# AI 漫剧创作平台市场研究

## 1. 研究范围与证据口径

- 截止日期：2026-07-13。
- 范围：AI 视频生成、AI 故事/短剧、端到端创作平台。
- 重点：非专业创作者、idea 到成片、角色一致性、多模型工作流、定价/商业模式、差异化空白。
- 证据：优先使用官方产品页、官方定价页与官方 FAQ。
- 限制：官方用户数是厂商自报口径，不等于独立审计的市场份额；官网能力描述不等于实测质量；价格、促销、模型名单会高频变化。

## 2. 关键结论

1. **多模型聚合正在变成标配。** Runway、LTX、Higgsfield、Katalist、OpenArt 和 Invideo 均已在单一产品内提供多家图像、视频、音频或语言模型，仅凭“接入更多模型”很难形成长期壁垒。
2. **端到端已从一键生成走向“自动初稿 + 可控编辑”。** Mootion 强调一条提示生成完整视频，Invideo 支持文本指令修改成片，LTX、Runway 和 Google Flow 则提供故事板、时间线、节点工作流、多镜头或自然语言精修。
3. **角色一致性已是基础卖点，但“多集叙事连续性”仍未成为大多数产品的显性核心。** Katalist、LTX、OpenArt、SkyReels 均明确宣称角色一致性、可保存元素或多模态参考；公开页面很少系统呈现跨集剧情状态、人物成长、关系、服装、道具和伏笔的连续管理。
4. **主流商业模式是订阅 + 月度 credits + 额外加购。** 不同模型、时长和分辨率消耗不同；商业许可、协作、数据隐私、组织管理与 API 常放在更高档。
5. **市场两端较强，中间层仍有空间。** 一端是专业创意套件，强调镜头、时间线、工作流和企业协作；另一端是一键社媒/营销视频。面向非专业用户、但能管理多集剧情、系列资产和整体预算的漫剧生产线并不突出。
6. **成本透明度可以成为核心产品力。** 市场普遍使用 credits，却很少把整部作品预算、每镜头估算、失败/废弃生成成本、低高成本模型路由做成创作工作流的一部分。
7. **建议定位不是“又一个 AI 视频生成器”，而是“非专业创作者的可控 AI 漫剧生产线”。** 竞争点应是系列级连续性、低门槛的创作决策、自动模型路由、局部重做、质量检查和作品级成本控制。

## 3. 市场结构

| 类型 | 代表产品 | 核心价值 | 对非专业用户门槛 | 与 AI 漫剧关系 |
|---|---|---|---|---|
| 专业创意套件 | LTX、Runway、Google Flow | 从概念/脚本到故事板、镜头、生成与编辑，高可控 | 中等 | 强间接竞品，可覆盖漫剧但定位更广 |
| 一键成片/内容自动化 | Mootion、Invideo | idea/脚本/文件到完整视频，自动补齐配音、音乐、字幕 | 低 | 在 idea 到成片上直接竞争，主要场景偏社媒、营销、教育 |
| 故事板/叙事工具 | Katalist、OpenArt Story | 脚本解析、镜头可视化、一致角色、一键故事 | 低到中 | 最接近功能竞品，公开定位偏单故事/单项目 |
| 模型超市/创意 App 平台 | Higgsfield、SkyReels | 多模型、多模态参考、特效预设、API | 中等 | 提供片段生成层，不等于剧集生产管理层 |
| 基础模型/API | Seedance、Veo、Kling 等 | 生成质量、原生音频、运动和参考控制 | 高 | 是平台供应层，不应与上层产品定位混淆 |

## 4. 竞品对比

### 4.1 LTX

**官方事实**

- 官方定位是面向电影、广告和创意团队的视频生产平台，声称覆盖从概念到 final cut。
- 支持从脚本、概念、图像或视频开始，提供动态故事板、时间线编辑、音效、镜头和关键帧控制。
- Elements 可保存 Characters、Objects、Locations 等，服务于跨场景一致性。
- 同一平台列出 LTX-2.3、Veo、Kling、Seedance、FLUX、GPT Image、Nano Banana 等，并提供节点式 Flows。
- 2026-07-13 页面显示：Free 800 一次性 credits；Lite $15/月；Standard $35/月；Pro $125/月，年付折扣后约 $12/$28/$100；商业许可从 Standard 起。

**相对空白/风险**

- 定位偏专业通用创意，功能面宽。
- 官网未突出漫剧的分集管理、跨集剧情状态和整部作品预算。

来源：[LTX 产品页](https://ltx.studio/)、[LTX 定价](https://ltx.studio/pricing)

### 4.2 Runway

**官方事实**

- 官方称有 50M+ 用户，但这是厂商自报数字。
- Runway Agent 支持通过对话创建端到端视频；另有 Multi-Shot Video App、Characters、编辑 Apps 和节点式 Workflows。
- 产品页列出 Gen-4.5、Seedance 2.0、Kling 3.0、Veo 3.1、Sora 2 Pro、Eleven 等模型。
- 2026-07-13 页面显示：Free；Standard $15/月；Pro $35/月；Max $95/月，年付约 $12/$28/$76；另有 Enterprise。
- Standard/Pro 的月度 credits 不结转；Max 最多结转一个月；额外购买 credits 不过期。

**相对空白/风险**

- 通用能力很广，产品复杂度和选择成本较高。
- 漫剧的剧本结构、分集连续性和面向小白的引导不是官网主卖点。

来源：[Runway 产品页](https://runwayml.com/product)、[Runway 定价](https://runwayml.com/pricing)

### 4.3 Google Flow

**官方事实**

- 将创作分为 Plan、Create、Refine，并提供项目 Agent。
- 聚合 Gemini Omni、Nano Banana 和 Veo 3.1；官方称 Nano Banana 擅长 subject consistency。
- 支持文本/图像/视频输入、自然语言编辑、Characters、Ingredients to Video、Scene Builder。
- 提供 Storyboard Studio，可写脚本、创建演员并可视化故事板。
- 2026-07-13 页面显示：免费 50 日度 credits；Google AI Plus $4.99/月；Pro $19.99/月；Ultra $99.99 或 $199.99/月，价格因地区而异。

**相对空白/风险**

- 依赖 Google 模型生态，不是中立模型路由层。
- 漫剧的分集、长期连续性和成本治理不是显性定位。

来源：[Google Flow 官方页](https://labs.google/flow/about)

### 4.4 Katalist

**官方事实**

- 面向电影人、广告人和内容创作者，明确强调“不需要 AI 经验”。
- 可导入脚本、CSV、Word、PowerPoint，自动分析角色、场景和活动，拆成镜头与故事板。
- 官方声称角色可在整个故事板保持一致，支持自定义角色和一键替换。
- Video Studio 可把故事板生成带配音、音乐和音效的视频。
- 计划内列出 Runway、Veo、Kling、Pixverse、WAN、Sora、LTX 等。
- 2026-07-13 页面显示：Essential $19/月、Pro $39/月、Unlimited $99/月，7 天试用；高档提供协作、Premiere/FCP 导出与 API。

**相对空白/风险**

- 强项是脚本可视化和故事板。
- 官网未突出系列 bible、跨集状态、自动质量检查与作品预算。

来源：[Katalist 产品页](https://www.katalist.ai/)、[Katalist 定价](https://www.katalist.ai/pricing)

### 4.5 OpenArt Story

**官方事实**

- 提供 One-Click Story、故事板、编辑器和可对话的 OpenArt Director。
- 定价计划按数量提供 consistent characters、personalized models 和 One-Click Stories。
- 官方称接入 100+ 图像、视频和音频模型，并提供 MCP。
- 2026-07-13 月付价：Essential $14、Advanced $29、Infinite $56、Wonder $240；商业使用权从 Advanced 起。

**相对空白/风险**

- “一键故事”和一致角色形成直接竞争。
- 定价以单次 Story/角色配额表达，官网未突出多集生产管理。

来源：[OpenArt Story](https://openart.ai/story)、[OpenArt 定价](https://openart.ai/pricing)

### 4.6 Mootion

**官方事实**

- 面向创作者、教师、电影人和故事创作者，明确强调不需要复杂工具。
- 声称可由“一条提示生成完整视频”，AI 会规划结构、节奏、视觉和声音。
- 支持从提示、脚本、音频、视频、文件或链接开始，自动生成成片。
- 可下载成片，也可下载脚本、图像和视频片段 ZIP 供第三方编辑。
- 官网自报 100M+ 视频、5M+ 创作者；这不是独立审计数字。
- FAQ 表明已是付费产品，实时价格需进入登录工作区，本次没有得到公开价格卡。

**相对空白/风险**

- 小白体验和输入面很强。
- 官网未将跨集角色连续性、模型路由和成本解释作为主要卖点。

来源：[Mootion 产品页与 FAQ](https://www.mootion.com/)

### 4.7 Invideo AI

**官方事实**

- 从 idea 加时长、平台、口音等信息生成脚本、视觉、配音、字幕和音乐。
- 支持用文本命令删场景、换口音、加开场等。
- 官方称适合新手，无学习曲线，主要展示社媒、营销、解说等场景。
- 付费计划官方称接入 200+ 图像、视频、音频和音乐模型。
- 商业模式为订阅 + credits + 按需加购；未用 credits 不结转。

**相对空白/风险**

- idea 到成片与低门槛能力强。
- 官网主场景偏信息型/营销视频，剧情、角色跨镜头连续性和分集不突出。

来源：[Invideo AI 生成器](https://invideo.io/ai-video-generator/)、[Invideo 定价](https://invideo.io/pricing/)

### 4.8 Higgsfield

**官方事实**

- 产品覆盖 Cinema Studio、Shorts Studio、Explainer、Marketing Studio、预设市场、Supercomputer Agent、MCP/CLI。
- 提供大量图像、视频、口型和音频模型；不同模型、分辨率、时长对应不同 credits。
- 计划含 characters 访问与不同角色生成配额。
- 2026-07-13 年付月均价：Starter $15（200 credits）、Plus $39（1000）、Ultra $99（3000）。
- Unlimited 只适用于指定模型/入口，可能动态调整速度，禁止自动化、凭证共享和转售。

**相对空白/风险**

- 模型和 App 广度强，但导航、选型和成本理解负担高。
- 系列漫剧的剧集、剧情与资产不是核心抽象。

来源：[Higgsfield 产品页](https://higgsfield.ai/)、[Higgsfield 定价](https://higgsfield.ai/pricing)

### 4.9 SkyReels V4/API

**官方事实**

- 支持文字、图像或参考生成视频，强调原生音画同步与多镜头过渡。
- Omni Reference to Video 声称可用图像、视频、音频控制跨场景角色、风格和故事连续性。
- API 使用预付 credits，1 USD = 100 credits；$30 首充起，更高充值档提供 10%-25% 奖励 credits。
- 视频按模型、是否含视频输入、分辨率和秒数计费。

**相对空白/风险**

- 生成与参考控制层很强。
- 不是明确面向非专业用户的多集漫剧项目管理产品。

来源：[SkyReels 产品页](https://www.skyreels.ai/)、[SkyReels API 定价](https://www.skyreels.ai/dev/pricing)

## 5. 能力与商业趋势

### 5.1 idea 到成片

**可验证事实**

- Mootion 和 Invideo 已明确占据“一句话/一个 idea 到完整视频”的语义。
- LTX、Runway、Google Flow 则把 Agent、故事板、时间线、多镜头、节点流和自然语言编辑组合起来。

**进入 PRD 的含义**

一键生成只应负责初稿。漫剧平台需在故事大纲、角色、分集、分镜、样片、成片之间设置低负担确认点，允许只重做有问题的局部。

### 5.2 角色一致性

**可验证事实**

Katalist 声称全故事板一致角色；LTX 可保存角色、物体和场景元素；OpenArt 按计划提供 consistent characters；SkyReels 声称多模态参考可保持跨场景角色、风格和故事连续。

**进入 PRD 的含义**

漫剧需要的不只是一张人脸参考图，而是结构化“角色圣经”：身份、年龄、体型、服装、表情、声线、关系、允许变化和禁止变化；同时需要场景、道具和色彩规则构成“世界圣经”。

### 5.3 多模型工作流

**可验证事实**

多家竞品已公开 100+/200+ 模型或详细模型清单；Runway、LTX、Higgsfield 还提供节点流、Agent 或按任务 App。

**进入 PRD 的含义**

非专业用户默认只选“更快、更稳、更好、更便宜”。系统按镜头类型、一致性、音频、预算和历史成功率自动路由，模型名仅作为高级设置。差异化应是调度质量和可解释性，而非模型数量。

### 5.4 定价与成本

**可验证事实**

- 入门订阅约 $12-$19/月（部分为年付折算），主流个人档约 $28-$56/月，高频档可达 $76-$240/月。
- 生成普遍按 credits 计费，模型、时长、分辨率影响消耗。
- 免费档常限制 credits、水印、模型或个人用途。
- 企业档常增加 SSO、集中结算、隐私、合规、SLA、API 与专属支持。

**进入 PRD 的含义**

生成前显示本次预估成本；作品级显示预算、已消耗、废弃/失败消耗和预计剩余成本；支持“草稿用低成本模型，定稿用高质量模型”的两阶段生成。

## 6. 差异化空白

> 以下是基于公开官网对比得到的研究推断，不等于竞品完全没有相关能力。

1. **多集叙事连续性**：前情、人物成长、关系状态、服装/道具变化、时间线、未回收伏笔需要成为跨集结构化状态。
2. **面向小白的导演式决策**：系统给出 2-3 个有解释的导演方案，用户做创作选择，连接“一键但不可控”和“专业但复杂”两端。
3. **可解释的自动模型路由**：默认选模型，并说明为什么、预计成本与时间；允许高级用户覆盖。
4. **剧集级成本和交付预测**：回答“完成 10 集需要多少钱、多久、预计重做多少镜头”，而不只展示单次生成 credits。
5. **自动质量检查与局部回退**：检查外观、服装、口型、声音、文字、时空连续性、画面缺陷和内容安全，失败只重做局部。
6. **可维护作品与来源追溯**：保留脚本版本、分镜、参考资产、模型、参数、生成记录、许可和版权信息。
7. **中文漫剧领域知识**：分集钩子、冲突密度、对话时长、竖屏构图、角色出场频次、每集回收点等模板化能力。

## 7. 建议进入 PRD 的定位

### 7.1 定位语句

**面向非专业创作者的可控 AI 漫剧生产线：用户只需提供一个想法，系统完成世界观、角色、分集、分镜、画面、配音、音乐、字幕和剪辑，同时保留每一阶段的选择、局部重做、成本控制和质量追溯。**

### 7.2 六个产品支柱

1. 故事到分集的 Agent 规划：idea 转换为故事圣经、角色圣经、分集大纲和可执行分镜。
2. 系列级一致性引擎：管理角色、场景、道具、声线、色彩、时间线和剧情状态。
3. 隐藏复杂度的多模型路由：按质量、成本、时延和任务适配自动选择。
4. 镜头级可修改：重写对白、重生单镜、锁定元素、替换配音和重排时间线。
5. 质量与成本控制台：生成前预估、生成中观测、生成后质检。
6. 成片交付与可追溯资产：多比例/分辨率、字幕和素材包导出，保留模型、参数、来源、许可和版本。

### 7.3 不宜作为唯一卖点

- “接入上百个模型”：已高度同质化。
- “一句话生成视频”：Mootion、Invideo、OpenArt 等已有明确占位。
- “角色一致”：应是底线能力，应升级为系列级角色/世界/剧情连续性。
- “电影级”：缺少可测量标准且已被高频使用。

## 8. 商业模式启示

1. **内部孵化期**：先用每部作品成本、idea 到成片时间、可接受镜头率、局部重做率验证经济性，不急于定 ToC/ToB。
2. **未来 ToC 假设**：订阅包含项目、存储和基础协作，credits 用于生成，支持额外加购；以作品成本估算降低 credits 焦虑。
3. **未来 ToB/工作室假设**：私有素材库、系列角色资产、品牌/画风规范、审批、权限、成本中心、API、数据隐私作为高价值权益。
4. **避免过早承诺无限生成**：视频成本受模型、分辨率、时长和峰值负载影响，应先建立可观测的单镜、单集和单部作品成本模型。

## 9. 可进入 PRD 的事实 / 不应直接写入的推测

### 9.1 可进入 PRD 的事实

- 多家代表平台已在一个产品内聚合多家图像、视频和音频模型。
- 市场已有从 idea/脚本到故事板、视觉、配音、音乐、字幕和完整视频的端到端产品。
- Agent、自然语言编辑、故事板、多镜头、节点流与镜头控制已经进入主流产品。
- 一致角色、保存角色/元素、多模态参考已经是公开功能或卖点。
- 订阅 + credits + 加购是主流计费方式，消耗随模型、时长和分辨率变化。
- 商业许可、协作、数据隐私和 API 普遍被用于订阅分层。

### 9.2 不应直接写入 PRD 的推测

- “市场没有产品能做多集漫剧”：官网未突出不等于完全不支持。
- “某产品角色一致性最好”：必须用统一测试集和人工评测验证。
- “一键生成即可得到可商用成片”：完整视频的营销声称不等于稳定叙事质量、无需人工审查或完整商用授权。
- “官方用户数代表活跃/付费用户”：Runway 和 Mootion 的数字都是官方自报。
- “入门订阅足够完成一部漫剧”：需按集数、时长、分辨率、重生率和模型路由实测。
- “多模型必然更高质或更便宜”：路由、参数、一致性和回退不成熟时反而会增加不确定性。
- “本报告价格会长期保持”：只能作为 2026-07-13 市场快照。

## 10. 建议后续验证

1. 用同一中文漫剧 brief 对 LTX、Runway、Katalist、OpenArt、Mootion 做 idea 到成片对照测试。
2. 用至少 3 个角色、5 个场景、20 个镜头测试外观、服装、声线和时空连续性。
3. 记录首次生成成本、达到可接受质量的累计成本、废弃生成比例和重做耗时。
4. 观察非专业用户是否被迫学习模型名、参数和提示词技巧。
5. 审查商业使用、训练数据、第三方模型、肖像与音色权利条款。
